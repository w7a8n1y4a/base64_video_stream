# Base64 Video Stream

Parameter | Implementation
-- | --
Description | Стримит base64-кодированные кадры видео по `MQTT` через `pepeunit-client`. Поддерживает `UI` с навигацией по библиотеке видео, воспроизведение, паузу, перемотку и случайный порядок. Кадры предварительно обрабатываются (CLAHE, DoG, дизеринг Флойда-Стейнберга) для отображения на монохромных `OLED` дисплеях `128×64`
Lang | `Python`
Hardware | `Any-PC`
Stack | `opencv`, `numpy`, `pillow`, `tqdm`, `pepeunit_client`
Version | 1.1.1

## Env variable assignment

1. `VIDEO_FPS` - Частота кадров видеопотока (кадров в секунду)
2. `UI_FPS` - Частота обновления UI (кадров в секунду)
3. `WIDTH` - Ширина кадра в пикселях
4. `HEIGHT` - Высота кадра в пикселях
5. `ITEMS_PER_PAGE` - Количество элементов на странице в списке библиотеки
6. `SEEK_SECONDS` - Шаг перемотки в секундах

## Assignment of Device Topics

- `encoder_action/pepeunit` - Принимает действие энкодера текстом: `One`, `Double`, `Long` (кнопка) или `Right`, `Left` (вращение)
- `full_frame_stream/pepeunit` - Отправляет base64-кодированный кадр (исходящий) для отображения на дисплее `SH1106`

## Work algorithm

1. Подключение к серверу `Pepeunit` по `HTTP`/`HTTPS`
2. Подключение к `MQTT` брокеру
3. Сканирование директории `videos/` на наличие `.mp4` файлов
4. Предварительная обработка видео: конвертация кадров в монохромный формат `128×64` (CLAHE, DoG, дизеринг Флойда-Стейнберга) и кэширование в `frames/` как base64 `.txt` файлы
5. Отображение UI: экран загрузки → главное меню (`Библиотека`, `Рандом`, `Действия`)
6. В режиме `Библиотека`: навигация по списку видео, просмотр статуса (`Ready`, `Pending`, `Processing`, `Error`, `Warning`), выбор видео для воспроизведения, возможность запускать дирректории как плей листы - двойным нажатимем кнопки
7. При двойном нажатии на видео в режиме `Библиотека` можно увидеть более подробную информацию о видео
8. В режиме `Random`: воспроизведение всех готовых видео в случайном порядке
9. В режиме `Actions`: очистка кэша `.txt`, просмотр информации о сервисе стриминга
10. При воспроизведении: последовательная отправка кадров в `full_frame_stream/pepeunit`, поддержка паузы, перемотки (`±SEEK_SECONDS`)
11. При получении действия в `encoder_action/pepeunit`: обработка навигации по UI и управление воспроизведением
12. Периодическая синхронизация состояния с сервером `Pepeunit`

## Installation

1. Создайте `Unit` в `Pepeunit`
2. Установите переменные окружения в `Pepeunit`
3. Скачайте архив c программой из `Pepeunit`
4. Распакуйте архив в директорию
5. Установите `uv` в вашу десктоп систему [uv github](https://github.com/astral-sh/uv)
6. Установите нужные пакеты командой uv sync
7. Добавляйте свои .mp4 файлы в дирректорию `videos/`, стриминг сам их будет конвертировать в `.txt`
8. Запустите стриминг при помощи команды uv run python main.py
